# OB Starter Kit

Entrega recompensas somente para personagens criados depois que o recurso esta instalado.
Logins comuns nao criam direito ao kit.

Edite `config.lua` para alterar dinheiro, itens e quantidades. Os codigos dos
itens precisam existir no `ob_inventory`.

O controle persistente fica em `ob_starterkit_claims`, uma linha por `user_id`.
