# ob_vehiclefailure

Controla somente dano e falha veicular da OB Framework.

- Mantem fumaca, fogo, vazamentos e deformacao nativos do GTA.
- Reforca os multiplicadores originais de handling por classe.
- Bloqueia a conducao quando a vida do motor chega ao limite configurado.
- Nao repara veiculos, nao controla chaves, nao consome combustivel e nao
  persiste estado. Essas responsabilidades permanecem nos recursos proprios.
