# Ícones dos itens

Coloque aqui os ícones PNG usados pelo inventário.

O nome deve ser o mesmo da chave em `data/items.lua`:

```text
bandage.png
medkit.png
adrenaline.png
water.png
bread.png
```

Quando não existir um PNG, a interface mostra o ícone em letra configurado no
item como reserva. Após adicionar ou trocar imagens, reinicie `ob_inventory`
ou o servidor para o FiveM incluir o arquivo no NUI.
